# flow — press kit

## Product
flow is a gated build harness for coding agents that enforces proof over vibes.

## Key stats
- **6 gates:** Idea, Research, Scope, PRD, ADR, and Contract before build starts.
- **2 verification layers:** Mechanical runner (`flow.sh`) + semantic rules (`SKILL.md`).
- **3 OS CI matrix:** Fully validated on Linux (Ubuntu), macOS, and Windows (Git Bash).

## Boilerplate
For developers running AI coding agents who are tired of "done" that means "the model said so", flow is the discipline layer that sits between the agent and the claim: a mechanical gate (`flow.sh`) and a semantic gate (`SKILL.md`) must both agree before a stage advances, and every transition leaves a receipt. Flow owns the gates and the receipts — never the runtime. Unlike workflow wrappers that make agents feel productive, flow makes progress provable: done equals world-state evidence, and a kill at a gate is a valid, honored outcome.
