# Direction C — Wordmark (Command Logotype)

- **Concept**: Command Wordmark (`/flow`). Constructed entirely from geometric vector paths with no live `<text>` tags. Integrates the terminal command slash `/` at an exact 75° angle as an intrinsic brand element.
- **Style Taxonomy**: Shape-built wordmark & letterform monogram (`mark_type: wordmark, letterform`, `type_style: display-custom, monospace, geometric-sans`, `technique: geometric-construction, letter-substitution`, `mood: minimal, developer-native, focused`).
- **Why It Fits flow**: Developers meet flow via the CLI prompt (`/flow`, `/flow next`, `/flow check C-001`). The mark elevates the terminal invocation into a typographic signature, pairing a disciplined 75° slash with balanced geometric letterforms.
- **Palette**: Signal Teal `#1AA3C4` (command slash), Gate Green `#22C55E` (mark accent), `currentColor` / Ink `#0F172A` (shape-built letters).
