# Direction D — Emblem (Receipt Seal / Badge)

- **Concept**: Gate-Pass Receipt Seal. Designed as a receipt/pass emblem celebrating a verified build outcome where mechanical and semantic gates agreed. Houses the dual gates behind a security seal ring with a verified pass checkmark.
- **Style Taxonomy**: Emblem / badge (`mark_type: emblem`, `technique: containment, bracket-code, geometric-construction`, `geometry: circle, grid-modular`, `mood: authoritative, verified, sturdy`).
- **Why It Fits flow**: Serves flow's core identity promise: "flow owns the gates and receipts." Acts naturally as a GitHub README badge sticker celebrating that an agent run passed all gates. Note: this is a symbolic receipt seal, NOT a tamper-evident attestation — capture-time tamper-evident provenance is an open roadmap item per `docs/adr/0001-discipline-layer-identity.md`.
- **Palette**: Signal Teal `#1AA3C4` (security seal ring & gate stanchions), Gate Green `#22C55E` (verified pass checkmark).
