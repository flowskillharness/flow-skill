# Direction A — Gate (Checkpoint Mark)

- **Concept**: Dual-Gate Threshold. The mark visualizes flow's foundational architecture: the mechanical gate (`flow.sh`) on the left and the semantic gate (`SKILL.md`) on the right. Both must agree before a stage advances.
- **Style Taxonomy**: Abstract mark (`mark_type: abstract`, `technique: geometric-construction, bracket-code, arrow`, `geometry: square, grid-modular`, `mood: technical, precise, structured, secure`).
- **Why It Fits flow**: Directly embodies the harness's rule that "flow owns the gates and receipts, never the runtime." The twin brackets frame the gate corridor, and the central chevron represents the verified pass state (`>`) advancing the build.
- **Palette**: Signal Teal `#1AA3C4` (gate stanchions), Gate Green `#22C55E` (pass threshold), Paper `#F8FAFC`, Ink `#0F172A`.
