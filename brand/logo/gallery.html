Brand Color Palette

10 tokens defined in brand/tokens.json. Governed by disciplined contrast and semantic usage ratios.

Teal Signal #1AA3C4 · rgb(26, 163, 196) Primary accent: badges, links-as-graphics, gate glyph, brand lines.
Teal Deep #0A4E5E · rgb(10, 78, 94) Teal text on light backgrounds (7.4:1 AAA), pressed states.
Teal Bright #5BC8DE · rgb(91, 200, 222) Teal text/graphics on dark (#0F172A) where Signal Teal is the minimum.
Ink #0F172A · rgb(15, 23, 42) Primary text on light; doubles as the terminal/dark-mode background.
Ink Soft #334155 · rgb(51, 65, 85) Secondary text, captions, table borders on light surfaces.
Mist #E2E8F0 · rgb(226, 232, 240) Primary text on dark backgrounds and subtle dividers.
Paper #F8FAFC · rgb(248, 250, 252) Light-mode background, cards, docs surfaces.
Pass (Green) #22C55E · rgb(34, 197, 94) Gate agreed; stage advanced. Status-only (≤ 5% surface).
Warn (Amber) #F59E0B · rgb(245, 158, 11) Degraded/skipped: debt opened, best-effort degrade.
Fail (Red) #EF4444 · rgb(239, 68, 68) Gate blocked; kill is a valid outcome. Never decorative.
Accurate Contrast Facts: Teal Signal (#1AA3C4) and Gate Green (#22C55E) on Paper (#F8FAFC) have contrast ratios of ≈ 2.9:1 and 2.3:1 respectively (decorative-graphic level, not meeting normal text thresholds). On Ink (#0F172A), contrast is ≥ 4.6:1 (AA normal / AAA large). Per brand-guidelines §1, teal body text on light backgrounds must use Teal Deep (#0A4E5E, 7.4:1 AAA).

Brand Usage & File Map

Normative rules from brand-guidelines §3 and repository file organization.

Do

  • ✓ Use the mono wordmark as-is; it must always be lowercase "flow".
  • ✓ Pair the logo with real state when context allows (glyph + pass dot).
  • ✓ Use the #gh-light-mode-only / #gh-dark-mode-only GitHub fragments to swap logo variants.
  • ✓ Maintain 1× mark height clearspace on all sides.

Don't

  • ✕ Don't recolor the wordmark with gate colors (pass/warn/fail) — status is data, not decoration.
  • ✕ Don't add taglines inside the clearspace or restack/rotate the mark.
  • ✕ Don't box the logo in a filled teal pill; the mark is stroke-first.
  • ✕ Don't typeset the wordmark in Inter or any proportional face.
