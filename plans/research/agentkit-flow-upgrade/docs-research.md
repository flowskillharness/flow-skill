## 4. Behavior patterns most relevant to flow (pattern-level, no copying)

- **P-1 Uniform CLI contract** (cli-conventions + doctor JSON envelope): named exit-code table, versioned `--json` envelope, preview/apply separation, "exit 0 ≠ healthy unless documented".
- **P-2 Named doctor checks**: registry of individually runnable, listable checks; advisory Notes vs actionable warnings split; unknown name = error; `--exit-on-fail` opt-in gate; offline mode; legacy-artifact and drift checks (peer: 33 named checks incl. `.agentkit`-managed markers + legacy CK artifacts).
- **P-3 Ownership + drift audit**: byte fingerprints for everything the installer wrote; classes clean/modified/unknown/shared; preserve-user-edits; read-only `audit`; snapshots before destructive writes (peer: pre-install snapshot default, `--no-backup` opt-out; `ak backups create` = sqlite `VACUUM INTO`).
- **P-4 Hooks as disclosed, inactive-by-default host adapters**: hooks are runtime-side automation, shipped as sidecars with explicit per-target drop/narrow disclosures; "not a security boundary"; fail-open on Grok; flow analogue must stay operator-installed and never gate-bearing.
- **P-5 State-aware onboarding conductor**: resumable, skip-completed, non-interactive = exit 2, explicit scope errors.
- **P-6 Channel + version pinning**: env-driven channel/version on installers; drift check when two layers disagree.
- **P-7 One-shot local dispatch** (`ak run <kit>/<skill> --target omp|dsh|grok`): ak frames the process, runtime owns model/auth — recorded as an **architectural conflict with ADR-0001** (flow framing/hosting agent processes = holding the process token). Evaluated in the gap matrix, not blanket-banned: any flow analogue requires an explicit ADR-0001 reopen first; no docs evidence this turn justifies that reopen.
- **P-8 Deterministic-mechanics compiler (AK Render)**: move regenerable bytes into deterministic tooling, return summary+diagnostics — flow already embodies this split (mechanical vs semantic layer); benchmark methodology page exists (`agentkit.best/benchmarks/ak-render-token-efficiency`, not crawled this turn).
